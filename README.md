# EMG Signal Processing – Muscle Symmetry During Walking

Academic biomedical signal processing project investigating the effect of different bag-carrying methods on upper trapezius muscle activation and left–right symmetry during walking.

Surface EMG signals were recorded bilaterally using a BIOPAC system under three walking conditions: no bag, backpack, and shoulder bag.

## Signal Processing

* DC offset removal
* Band-pass filtering (20–450 Hz)
* RMS calculation
* Left–right muscle activity comparison using an Asymmetry Index

The project combined physiological signal acquisition, EMG signal processing, and quantitative analysis to evaluate changes in muscle activation patterns during walking.
